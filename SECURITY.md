## 🚨 Reporting a Vulnerability

The MobCare project takes the security of its users and the privacy of collected telemetry very seriously.

If you discover a security vulnerability or exploit (such as unauthorized privilege escalation, PIN gate bypass, or sensitive telemetry exposure), please **DO NOT create a public GitHub Issue**. Publicly disclosing an exploit puts active users at risk.

### Responsible Disclosure Process:

1. **Email Disclosure:**
   Please send a detailed report to the repository owner via GitHub Security Advisory or direct email.
2. **Include in Report:**
   - Affected device model & Android version (e.g., Android 14 / API 34).
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - Potential impact of the vulnerability.
3. **Response Timeline:**
   - You will receive an initial response acknowledging your report within **48 hours**.
   - A triage and verification assessment will be conducted within **5 business days**.
   - If verified, a patch will be deployed and a GitHub Security Advisory credit will be issued.

Thank you for helping keep MobCare safe for everyone!
